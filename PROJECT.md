# Triumph! War 2099 reconstruction

Fan reconstruction of the original game by Anthony Lopes / DarkSun Games. Original artwork, audio and decoded source data retain their authorship; no new license is granted for them. The optional generated Windows MIDI sample bank is machine-local and excluded from Git and default packages.

The editable original Multimedia Fusion project was not recovered. Engine/AI behavior and many timings are reconstructed; approved custom design differs deliberately from the original.

`milestone-playable-2026-10-04` preserves the prototype through rally flags. Local `main` is the accepted baseline; task branches carry new development and records. Publication scope and remote visibility must be checked in docs/STATUS.md before publishing.

Repository instructions: AGENTS.md. Fresh-session workflow: docs/WORKFLOW.md. Current design, architecture, verification and backlog live under docs/.

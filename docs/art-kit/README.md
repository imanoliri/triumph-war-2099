# Map art handoff kit — TRI-033

Start here in a checked-out repository. This kit prepares local reference material for a future approved art ticket; it installs no art and grants no publication permission. All paths in the manifest are repository-relative. Keep this folder with its referenced repository files when handing it to another AI; this is a self-contained instruction set, not a redistribution package.

1. Director: use [director workflow](director-workflow.md) and fill [dispatch prompt](artist-prompt.md).
2. Artist: follow [artist workflow](artist-workflow.md), [geometry contract](contract.md) and [filled Split Ridge prompt](split-ridge-prompt.md).
3. Inspect [reference library](library.png), [element atlas](elements.png), [sprite atlas](sprites.png), [palette](palette.png), and [fixed-mask overlay](geometry.png). Labels identify recovered versus custom sources; atlas enlargement is for inspection only.
4. Read [machine-readable baseline](manifest.json) and [sprite hotspot catalog](sprites.json). Run `node docs/art-kit/catalog.cjs` then `python docs/art-kit/render.py` with a local Pillow-capable Python to refresh the kit only. Do not run a runtime asset builder for an art-only ticket. `python docs/art-kit/verify.py` checks paths, dimensions, hashes, labels and mask packing.

The baseline is implemented Split Ridge (TRI-032), with 25 immutable actor/object hotspots. A is its approved schematic; B Relay Basin and C Switchback Mesa are saved concepts, not implemented variants. Existing screenshots document partial historical browser smoke: tactical screenshot is final TRI-032 art; live screenshot predates its last facet refinement. They contain live entities/HUD and must never become terrain. See [original playtest and limitations](../playtests/2026-10-04-split-ridge.md).

Reference images and sprites were recovered from Anthony Lopes / DarkSun Games. [Provenance](../../assets/provenance.json) retains the explicit original executable path and hash; this kit neither reads nor modifies that installation. Split Ridge art is newly authored deterministic artwork, palette-inspired only. Previews deriving from recovered images remain local references subject to existing distribution restrictions. No MIDI bank, remote upload or external account is involved.

Workflow files are deliberately repository Markdown, not an installed Codex skill: [WORKFLOW](../WORKFLOW.md) recommends ordinary instructions rather than per-feature skill duplication. Specialized raster generation may invoke the available `imagegen` skill; the artist must read its exact installed SKILL.md first and record it in the session. Deterministic SVG/Pillow/canvas authoring needs no generative-image skill. No model selection, tool install or plugin is required to use this kit.

Element atlas visual reading (inferred labels, not recovered object names): 515/516/517/518/510 are lit cliff faces/edges, 512 a rock cap, 534 small stones; 519 and 537/538/543/544 are sand fill/corner transitions; 521 is a purple floor patch, 533 organic lines and 478/472 alien remains. The last group is context, not a recommendation to add entity-like scenery. Shading is baked into cliff pixels; consult the full recovered Desert Rocks map for edge/shadow treatment rather than assuming a separate shadow sprite. Current custom terrain uses layered warm-gray rock, dark outlines and a thin lit rim. Palette swatches list actual custom generator colors, derived from recovered palette, not an exhaustive recovered color bank.

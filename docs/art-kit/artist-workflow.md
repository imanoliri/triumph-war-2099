# Bounded artist session

Trigger: an approved art ticket and director dispatch specify the map/output scope. Read AGENTS, WORKER, that task/latest journal, this kit README/contract/manifest and the map prompt. Resolve all manifest paths from the repository root. Verify branch/status and baseline hashes before work; preserve unrelated edits. Do not modify the installed game or regenerate recovered assets.

Choose an authoring method: deterministic Pillow/tile drawing or SVG/canvas fits exact geometry and reproducible layered source. Raster generation/editing fits textures and stylistic studies; use the installed `imagegen` skill, read its SKILL.md first, announce/record skill use, inspect local references before edits, and follow its reference-image/tool requirements. Generated raster is an art input: clip/composite it against immutable geometry in an editable authoring source, then inspect the result. A model-generated collision mask is never acceptable. Do not use imagegen for existing vector/code-native edits. No skill/tool installation is required; missing specialized tools are a limitation to report to director.

Inspect library, terrain, mask, source map and sprites separately. Identify scene lighting and cliff/shadow conventions from recovered references while retaining their provenance. The recovered element atlas uses individual backdrop image handles from Desert Rocks; sprite atlas marks hotspots. Create original textures inside permitted regions, with low-contrast detail on traversable sand. Keep reference overlays out of exported terrain.

Before Review: rebuild from saved editable source; check 1024×768 final dimensions; compare mask bytes and immutable file hashes; inspect before/after and actor-overlay at native pixel scale and enlarged nearest-neighbor detail; inspect every corridor/hotspot and final raster for baked entities or misleading collision cues. Check references and source provenance. Run ticket-relevant checks per AGENTS/WORKFLOW; record browser evidence only if actually observed. Save commands, seed/prompts and limits in initial session, update supported acceptance, commit scoped files and return exact Review paths/SHA/next action to director. Never merge, publish, alter director board or delegate.

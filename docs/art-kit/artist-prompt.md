# Reusable compact dispatch

Use the existing concise linked worker contract printed by task preparation/board dispatch. It already identifies the ticket, checkout, branch, task and initial/latest session and limits worker authority. Append only:

> Art brief: read [exact repository-relative filled-brief path] and follow its linked kit references.

Fill the path before sending. Do not paste the full artist brief, reference files or conversation history. Keep the combined dispatch within the existing compact contract convention; do not replace the generated worker contract with a second policy block.

## Repository brief preparation

Save detailed art instructions in the approved task or a linked brief file. Start from [Split Ridge brief](split-ridge-prompt.md) for that map. Fill map ID, approved style, output-only versus explicitly approved installation scope, custom-owned output directory and immutable baseline snapshot/commit before dispatch. Link [README](README.md), [contract](contract.md), [artist workflow](artist-workflow.md), [manifest](manifest.json) and relevant style references from that file. Task/session paths remain in the generated contract, avoiding duplicate run metadata in the brief.

The repository brief must require editable source/reproducible build or layers, final PNG, provenance/change notes, native-scale before/after and actor-overlay previews, unchanged-mask evidence and relevant checks. Preserve geometry/gameplay, visually verify no baked entities, record tool/skill use and limitations, and stop at Review under WORKER. The filled Split Ridge brief already supplies these details; another map needs its own approved baseline rather than silently reusing Split Ridge geometry.

# Director art intake / dispatch / review

Trigger: the user approves one bounded map beautification ticket. Until then this kit is reference preparation. Follow [DIRECTOR](../DIRECTOR.md) for authority/board handling, [WORKFLOW](../WORKFLOW.md) for preparation and squash review, and [WORKER](../WORKER.md) for worker ownership. Those files remain policy; this page supplies art-specific evidence.

Intake: identify map, approved visual direction, whether output-only or runtime installation is authorized, and editable-source expectations. Copy the fixed contract into task acceptance by reference. Record allowed output directory and explicitly immutable files. Ask material style/layout questions through normal director contact; do not authorize B/C merely because references exist.

Dispatch: prepare one isolated ticket branch/worktree using the existing preparation workflow. Save the detailed filled artist brief in the repository with links to kit README, contract, manifest and style references. Send the existing generated concise linked worker contract plus one exact filled-brief path as shown in artist-prompt.md. Do not paste the brief or referenced files into dispatch; the artist follows their links and spends context on art. Use the initial session; do not create recursive workflow tickets/sessions. Maintain default model unless the user requests otherwise. Dispatch one worker, no nested delegation or additional chat creation.

Review: inspect final terrain at 1:1 alongside original baseline, editable source/layers, sprite-overlay comparison and fixed-mask overlay. Verify output dimensions, no baked live entities/HUD, readably different blocked rock versus clear sand, unchanged top strip and all accesses. Require provenance, exact generation/build commands, unchanged PNG/packed-mask SHA-256 and bit comparison, focused checks and exact scoped commit. If runtime installation was approved, require relevant regression/browser evidence under PLAYTEST, separately from simulation. Existing historical screenshots are not a new playtest. Send bounded findings back to the same worker. User-facing preview should link the output images and source before asking for any remaining approval.

Integration: use existing director review/squash/checkpoint policy only when accepted. Do not publish recovered references or originals; local approval is not external distribution authority. For this kit ticket, next action is user review of the kit and selection of a separate art ticket.

# Backlog intake

The [local project board](BOARD.md), generated from `board.json`, owns ticket workflow status. Linked task records own scope and acceptance. Stable TRI IDs remain unchanged; no GitHub issues or native project board have been created or synchronized.

## Bug report requirements

Mission, difficulty, browser, build/commit, expected and actual result, exact steps, screenshot/video if useful, and Remaining HUD values. Distinguish source-game behavior from desired new behavior.

## Feature requirements

Desired player outcome, agreed UI/controls, affected units/missions, acceptance criteria and deliberate exclusions. Balance changes require updating DESIGN and Units descriptions. Director records user agreement before Ready.

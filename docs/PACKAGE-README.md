# Triumph! War 2099 — playable local package

Open index.html in a desktop browser. This ZIP contains the runtime, not the development tools. Development instructions and task/session records live in the source repository.

- Commander buttons select the unit controlled by WASD, V/B and mouse. Hold left mouse to aim/fire; right mouse throws a grenade. Physical keyboard bindings support German QWERTZ; Controls shows all presets.
- Drag selects troops, Shift adds. Right-click ground attack-moves, double right-click empty ground force-moves, enemy clicks focus attacks, double right-click usable objects sends units to use them.
- Pause/Space/Escape freezes play while keeping selection and orders available. Units execute queued orders on resume. Enter starts/advances; F2 restarts.
- Rally at top-right, or R, toggles flag placement. Left-click ground places flags, right-click removes one, Escape exits. Yellow/bronze/BLITZ soldiers/tanks/robots use the nearest reachable flag; commandos ignore flags. Flags reset per mission.
- Units contains current health, damage and firing descriptions. Remaining identifies unresolved mission requirements. Some missions require terminals, wave quotas or crystal extraction after clearing combatants.

Original game and assets: Anthony Lopes / DarkSun Games. The editable original source was not recovered; this engine/AI is reconstructed and includes custom balance/specialists. Assets retain their authorship; no new license is granted. assets/provenance.json records source information.

Original MIDI performances are included. Default packages use fallback synthesis unless an optional local Windows sample bank is present. A personal package containing that bank must not be published. Audible fidelity and comprehensive browser acceptance remain unverified; consult source-repository status/playtest records for evidence.

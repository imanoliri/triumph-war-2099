# Planet dossier index

Each dossier is a proposal. A place is distinguished by routes, mission problems and local forces, alongside its visual identity. No new mechanic is approved simply by appearing here.

This combined table preserves all fourteen settings in the recorded brainstorm, including the earlier frontier, under-city, jungle, industrial and mercenary settings. Planet names are working proposals. Enemy assignments for desert and under-city were explicitly changed by the user on 2026-10-05; other assignments remain proposals.

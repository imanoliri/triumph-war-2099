# Campaign design pack

Planning prepared 2026-10-05. The user approved preparing documentation and agent workflows. Names, sequence, missions, units and mechanics below are proposals for refinement, not approved runtime changes.

User direction: a continuing expedition with occasional missions commanding independent local factions; varied planets, environments, human forces and adapted bugs. Snow, maritime and capital worlds are explicit requested settings.

Start with [expedition campaign](expedition.md), the individual [planet dossiers](planets/README.md), [mission briefs](missions/README.md), and [agent kit](agent-kit.md). Earlier discussion remains in [campaign brainstorm](../campaign-worlds.md). Each brief carries its own unresolved choices; an agent must receive one approved ticket rather than implement the entire pack.

## Design decisions still open

- Persistent army versus mission-specific rosters; casualties, recruitment and recovery.
- Linear chapters versus optional destinations and return visits.
- Number of missions per planet, campaign length and first playable chapter.
- Whether local-faction command is a standalone roster or shares expedition commanders.
- Resource carryover and consequences of optional objectives.
- Exact unit statistics, difficulty targets and environmental mechanics.

Choose a first mission, refine its objective and forces, approve its observable acceptance, then dispatch one worker. Campaign scaffolding, unit mechanics, map layout, art polish and balance should become separate bounded tickets when needed.
